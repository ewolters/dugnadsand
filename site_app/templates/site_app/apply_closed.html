Applications are closed

Trial period · to {{ trial_ends }}

Dugnadsand is running as a trial. Whether it continues past {{ trial_ends }} has not been decided, and applications are not being taken until it is.

The reason is that admitting an organization is a commitment to operate the network for it. That commitment cannot honestly be made while the network's own future is open. An organization admitted next month into something that closes the month after has been done a disservice rather than a favour.

What this is not

It is not a waiting list, and there is nothing to join in the meantime. Organizations already admitted are unaffected and the network continues to run for them through the trial period.

Organizations with an interest

A note is welcome, and is more useful than an application would be: what an organization does, and what it would use the network for. The open question is whether this should exist rather than who should be in it, so the answer to the first is worth more than a queue for the second.
